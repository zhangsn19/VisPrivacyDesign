# Visual Inferential Privacy — Study Materials

Materials for **design elicitation, synthesis into six design concepts, and user evaluation**. Start with the [concise English appendix](APPENDIX.md).

| Material | Where to start |
|---|---|
| Design elicitation | [Task guide](01_Design_Elicitation/Design_Proposal_Guide.md) · [blank background form](01_Design_Elicitation/Participant_Background_Form.md) |
| Six designs, D1–D6 | [Illustrated catalog](02_Six_Design_Concepts/Six_Design_Concepts.md) · [synthesis description](02_Six_Design_Concepts/Design_Synthesis.md) |
| Evaluation | [Procedure](03_Evaluation/Evaluation_Procedure.md) · [rating and ranking questions](03_Evaluation/Evaluation_Questionnaire.md) · [recovered background questions](03_Evaluation/Background_Questionnaire_Items.md) |
| Interactive demonstration | [Six-design prototype](prototype/README.md) — open `prototype/index.html` in a browser |
| Evaluation-flow reference | [Study reference](study-reference/README.md) — storyboard, interaction, ratings, and ranking |

The standalone demonstration is the simplest way to inspect the six designs. The study reference preserves the available evaluation flow and supports local inspection with a fictional participant code. Their intended uses and version differences are documented at each entry point.

The original [design proposal](design-proposal.md) is retained. Participant records, responses, signatures, and private source notes are not included.

**Author review:** the final administered question wording, scale anchors, and UK-specific OPLIS items still require confirmation. See the short [review notes](REVIEW_NOTES.md). This repository is a consolidated material package; it does not claim to include the final Prolific collection deployment.
