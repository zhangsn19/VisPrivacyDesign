# Background Questionnaire Items

The following English text is transcribed from the question-bank constants in `prototype/script.js`. The code labels these banks OPLIS-12-US, IUIPC-10, and the Jian–Bisantz–Drury trust-in-automation measure. These labels identify the source's intended instruments; this transcription does not establish equivalence to published standardized wording or to the final administered form.

The demonstration does not administer these background questions. Their order in the actual study, response labels for the 1–7 items, and the UK-specific OPLIS wording remain to be confirmed.

## OPLIS: US question bank

The source contains the following question text and keyed answers. For the statement items, the collection records use true/false/unknown values; exact on-screen option labels are not present in the demonstration source.

### 1. inp03

### 3. inp05

### 4. tea02

What is a cookie?

- **a.** A text file that helps a website recognize a returning user
- **b.** A program that disables data collection
- **c.** A computer virus transferred by websites

### 5. tea03

What does cache mean?

- **a.** Buffer storage that can make browsing faster

Source answer key: **a**.

### 6. tea04

- **a.** A program disguised as useful software that performs another function
- **b.** Software that protects against malware
- **c.** A harmless program made for fun
- **d.** A virus that no longer exists

## Scoring information available

OPLIS keyed answers are reproduced above. The demonstration does not implement the scoring procedure. In the inspected collection records, the stored IUIPC summary equals the mean of the ten item values. The stored trust summary equals the mean after reversing items 1–5 with `8 − response` and leaving items 6–12 unchanged. These are observations about the recorded summaries, not proof of the final instrument specification.

The UK-specific OPLIS questions and the final check questions are not present in this source. Do not substitute the US legal-knowledge items for the UK variant without confirming the administered form.
