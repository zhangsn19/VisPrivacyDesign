# Visual Inferential Privacy Prototype

This folder contains an anonymized interactive MVP for exploring six visualization directions for visual inferential privacy.

Open `index.html` in a browser, or serve this folder with any static HTTP server. Use the scenario tabs, prototype navigation, and controls inside each prototype to inspect evidence, inferred risks, and possible protection actions.

This demonstration is intentionally separate from the research data-collection interface. It contains no participant records, responses, identifiers, recruitment links, contact details, or author information.
